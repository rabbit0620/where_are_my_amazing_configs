这个库是干什么的

linux的一个机制是一切皆文件，很多软件如neovim,wezterm等是靠着配置文件来定制的，所以就有了这种管理方式，
把所有的配置文件单独拿出来，放在github上，这样如果你进入了一个新系统环境，像是重装系统，或换了一个新的发行版，你也不用去找教程或者是问ai，把这些配置过的软件再配置一遍了
而是直接用这个repo把自己的配置拿回来

我在这个库里放了大部分的配置文件
还有我的软件清单列表，里面放着我主动安装过的所有软件
有了这些，我就再也不用一遍一遍去找，有什么linux必装软件了，每次都是这几样，什么gimp,inkscape,python,r之类的

当然，我现在的技术力还不是那么强。我还有很多东西要学，有很多事情目前还做不到
不过我相信，以后会做到的

这个库以后就充当我的配置大本营了
